## 📖 家人使用說明｜Family Quick Start

家人第一次使用電子紙天氣相框，不必安裝工具，也不需要 SSH。

- **[📱 圖文操作說明書（繁體中文）](https://crazylittlej.github.io/epaper-weather-dashboard/)** — 含實機成果展示、Wi-Fi 配對實機照片、換城市與照片、常見問題。
- **[🖨️ A6 QR Code 列印小卡](https://crazylittlej.github.io/epaper-weather-dashboard/print-a6.html)** — 印出貼在裝置背面，手機掃描即可閱讀說明。
- **[📝 家人版 Markdown 說明](docs/README.md)** — 不依賴 GitHub Pages，可直接在 Repository 閱讀。

**首次設定**：掃描裝置螢幕左邊 QR Code → 加入 `ePaper-Setup-XXXX` → 掃中間 QR Code／開啟 `http://10.42.0.1/` → 輸入 2.4 GHz Wi-Fi、城市與目前的 6 位數 PIN。

**日常設定**：手機連上同一個家中網路，再開啟 `http://epaper.local`（僅區域網路可用）。

> 備註：上方 Pages 網址必須先完成 `main /docs` 的 GitHub Pages 部署才可使用；A6 小卡 QR Code 與首次 Wi-Fi 配對 QR Code 是不同用途。
